# 我好害怕 · dsh-i-hao-hai-pa

> 用户骂 DSH 一句，界面像被地震掀了一样塌掉：一行一行先左右大摆幅地抖，再翻滚着坠下去，堆成一地瓦砾，
> **一直瘫着不动，直到 DSH 开始回答才从下往上长回去**。
>
> **纯搞怪插件，仅供娱乐。不联网、不上传、不收集任何数据、不调用任何模型。**

上架版：**1.2.0**。存档在 [`../dsh-i-hao-hai-pa-versions/1.2.0/`](../dsh-i-hao-hai-pa-versions/1.2.0)。

## 会塌哪些地方

三个面板各自拆块、各自堆叠，互不干扰：

| 面板 | 根节点 |
|---|---|
| 左侧栏 | `[data-dsh-sidebar-root]` |
| 右侧编辑区 | `[data-dsh-better-sidebar]` |
| 中间列（标题栏 + 标签行 + 消息流 + 输入框） | `[data-dsh-center-col]` |

**不枚举任何具体入口**：矮的元素本身就是一块，高于 64px 的容器继续拆，超过 200px 一律拆开，
`display: contents` 的包裹层展开后继续往下找。

## 什么时候触发

1. **自动（主要方式）**：在输入框里按回车，或点发送按钮——**在你要发出去的那一刻**直接读输入框里的文字判定。
   不依赖消息行的类名（那层 DOM 找不到稳定标记），所以很稳。
2. **双击**面板空白处（会话行、目录行、按钮、输入框上的双击不会被拦，重命名照常）。
3. **右下角小条**的按钮。

## 怎么判定「在骂我」

纯本地正则，命中即触发，不发请求、不花 token、零延迟。

- 词表约 80 条：傻逼/智障/垃圾/废物/卧槽/滚蛋/闭嘴/去死… + stupid/idiot/bullshit/shut up/fuck…
- 英文按**整词**匹配（`\b`），不会误伤 `class`、`hobby` 这类词
- 先剥掉代码块、行内代码、引用块、链接——引用别人的脏话不算
- 超过 400 字的消息放行（那多半在干活）
- 同一句 8 秒内不重复触发；两次之间 20 秒冷却

## 时间线

| 阶段 | 时长 |
|---|---|
| 前震（±34px 低频大摆幅 + 高频抖动） | 340ms |
| 塌落（翻滚，±40° 旋转） | 560ms |
| 余震（四段回弹） | 520ms |
| **保持瘫着** | **直到 DSH 开始回复**（或 15 秒兜底） |
| 重建（从下往上，一块块飘回） | 700ms |

「回复开始了」有两条独立信号，任一成立就重建：生成中的**停止按钮**出现，或者**聊天区文字开始变长**（流式输出）。

## 隐私与安全

一句话：**它只在这个页面里动，不跟外界说任何话。**

对 `client.js`（1212 行）+ `index.js`（9 行）逐项检查的结果：

| 检查项 | 结果 |
|---|---|
| `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` / `EventSource` / `importScripts` | **0 处** |
| 任何 `http(s)://` 外部地址 | **0 处** |
| `localStorage` / `sessionStorage` / `indexedDB` / `document.cookie` | **0 处** |
| `navigator.clipboard`（读剪贴板） | **0 处** |
| `eval` / `new Function`（动态执行） | **0 处** |
| 第三方依赖 / 构建步骤 | 无，纯手写 JS，可直接读 |

**它读什么**

1. **输入框里的文字** —— 只在你按回车/点发送的那一刻读一次，用来判断是否命中词表；
2. **面板的 DOM 结构** —— 为了把界面拆成块、算每个块的位置和尺寸，会读元素的 `getBoundingClientRect()` 和 class 名。

**它不做什么**

- 不读剪贴板、不读文件、不读其他应用；
- 不写任何持久存储，不往页面里塞自己的元素（只有一个空的、不可见的挂载容器）；
- 不向会话里追加任何消息，不影响模型看到的内容；
- 判定完全在本地用正则完成，**不调用模型、不消耗任何 token**。

**它留下的痕迹**

演出结束会把所有动画 `cancel()`，并还原临时改过的内联样式。此外还有三道保险：
最多等 15 秒自动重建、页面被切走立刻收场、60 秒看门狗强制清理。退出 DSH 后不会有任何残留。

如果你要用它，建议直接把 `client.js` 通读一遍——1212 行，没有打包压缩。

## 触发方式（定稿版没有任何屏上控件）

1. **自动**：发消息时（回车或点发送）直接读输入框判定，命中脏话/辱骂词表就演；
2. **手动预览**：在任意面板的**空白处双击**（会话行、目录行、按钮、输入框上的双击不会被拦，重命名照常）。

## 开发与迭代

```bash
./push-live.sh              # 把当前 client.js 推到运行中的 Host，1 秒内热更新
./push-live.sh 0.27.0       # 顺便改版本号
```

`client-hmr` 每 500ms stat 轮询正在服务的那份 bundle，mtime 一变就热替换，**不用重启 DSH**。
（注意：改的是哪个文件很重要——Host 服务的是它启动时解析到的那一代目录，脚本会把所有现存
generation 都覆盖一遍，命中哪个都能生效。）

正式安装（存档用）：

```bash
plugin_manager install_bundle <这个目录的绝对路径>
```

替换安装会生成新的不可变 generation，**正在运行的 Host 仍服务旧的那一代**，要重开 DSH 才换。

## 已知边界

- **掉不出面板**：三个面板外层都有裁剪容器，块只能在面板内部塌、堆在面板底部。试过克隆绕过和临时放开
  `overflow`，都没能稳定越过这条线。
- 逐字坍塌做过一版（每个字一个克隆 + 独立动画），效果成立但 500 字就是 500 个动画，已撤掉。
- 开启系统「减少动态效果」时不播放。
